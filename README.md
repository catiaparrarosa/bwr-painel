# BWR Painel de Gastos — GitHub Pages / PWA

Arquivos prontos para publicação no GitHub Pages.

## Como publicar

1. Crie um repositório no GitHub.
2. Faça upload de **todos os arquivos e pastas** deste pacote na raiz do repositório.
3. Confirme que o arquivo principal se chama **index.html**.
4. Acesse **Settings > Pages**.
5. Em **Branch**, selecione **main** e clique em **Save**.
6. Aguarde alguns minutos e abra o link gerado pelo GitHub Pages.

## Instalar no celular

- Android/Chrome: abrir o link > menu de três pontos > **Adicionar à tela inicial**.
- iPhone/Safari: abrir o link > compartilhar > **Adicionar à Tela de Início**.

## Arquivos incluídos

- `index.html`: painel principal já ajustado.
- `manifest.webmanifest`: configurações do app instalado.
- `service-worker.js`: suporte básico para cache e comportamento de PWA.
- `icons/`: ícones do aplicativo.
