# BWR Painel de Gastos — GitHub Pages / PWA

Arquivos prontos para publicação no GitHub Pages.

## Como publicar

1. Acesse o repositório no GitHub.
2. Faça upload de todos os arquivos e pastas deste pacote na raiz do repositório.
3. Confirme se o arquivo principal está com o nome `index.html`.
4. Acesse **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Em **Branch**, selecione `main` e a pasta `/(root)`.
7. Clique em **Save**.
8. Aguarde o link do GitHub Pages ficar disponível.

## Arquivos incluídos

- `index.html`: painel principal ajustado.
- `manifest.webmanifest`: configuração do app instalado.
- `service-worker.js`: cache básico para melhor comportamento como PWA.
- `icons/`: ícones do aplicativo com a identidade BWR.
- `logo-bwr.png`: logo extraído do próprio painel, mantido como apoio.

## Observação

Depois de atualizar os arquivos no GitHub, remova o app antigo da tela inicial do celular e adicione novamente para o novo ícone aparecer.
